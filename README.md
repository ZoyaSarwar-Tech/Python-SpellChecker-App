# 🔤 Spell Checker App (Python GUI)

A simple and beginner-friendly **Spell Checker Application** built using **Python**, **Tkinter**, and **TextBlob**.
This app allows users to enter a word and check whether it is correct or get suggestions for correction.

---

## 🚀 Features

* ✅ Check correct spelling
* ❌ Detect incorrect words
* 💡 Suggest correct word automatically
* 🖥️ Simple and clean GUI (Tkinter)

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* TextBlob (Spell Checking Library)

---

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/spell-checker-gui-python.git
cd spell-checker-gui-python
```

### 2. Install dependencies

```bash
pip install textblob
```

### 3. Download TextBlob data

```bash
python -m textblob.download_corpora
```
---

## ▶️ How to Run

```bash
python app.py
```
---

## 🧠 How It Works

1. User enters a word
2. TextBlob processes the word
3. App checks:

   * If correct → shows "Correct Spelling"
   * If incorrect → suggests correct word
